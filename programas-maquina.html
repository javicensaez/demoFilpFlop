Codifica el programa

Resuelve las etiquetas y traduce cada instrucción y cada dato a una palabra de 16 bits.

Base de datos: 


        
Las instrucciones empiezan en 0 y ocupan una dirección cada una. Los datos se sitúan consecutivamente desde la base indicada. Las etiquetas de salto apuntan a instrucciones; los operandos de datos apuntan a variables.

        
00 ADD · 01 CMP · 10 MOV · 11 BEQ
Formato: código (2) | fuente (7) | destino (7). En BEQ se ignora fuente. Los datos se codifican como valores de 16 bits, sin código de operación.
