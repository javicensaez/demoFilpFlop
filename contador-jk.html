Contador síncrono de 4 bits

Cuatro biestables JK cuentan de 0 a 15. Todos reciben el mismo reloj y cambian en el flanco ascendente.

Controla el contador

Q3 Q2 Q1 Q00000Decimal 0 · Hex 0

1 lógico 0 lógico · Q0 es el bit de menor peso. Las entradas de las AND están identificadas por sus señales.

¿Cuándo conmuta cada bit?

J = K = 1 invierte Q; J = K = 0 conserva Q. En cada subida se usan los valores anteriores al flanco, de forma simultánea.

BiestableJ = KValor actual

RESET̅ = 0 borra los cuatro bits inmediatamente, sin esperar al reloj. Al volver a 1, espera a la próxima subida. Después de 1111, el contador vuelve a 0000 (módulo 16).
